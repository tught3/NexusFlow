## 3. 임시 처리 (저장되지 않는 전송)
- **음성 인식(STT):** 온디바이스 처리(speech_to_text). 원본 음성은 저장하지 않음.
- **AI 구조화:** 전사 텍스트를 Supabase Edge Function(openai-proxy)을 경유해 OpenAI API로 전송해
  구조화합니다. 전송되는 것은 사용자 입력 텍스트이며, OpenAI 측 저장 정책은 [TODO: API 데이터 사용
  옵트아웃 설정 확인 후 기재]. 처리 결과(구조화 기록)는 사용자 계정에 저장.
- **OCR:** 스크린샷 텍스트 추출은 온디바이스(ML Kit). 이미지 자체는 전송하지 않음.

## 7. 민감 권한 관련 (별도 선언 필요)
앱이 선언하는 민감 권한과 근거 — Play Console 권한 선언서에도 동일 내용 기재:
| 권한 | 근거 |
|---|---|
| RECEIVE_SMS / READ_SMS | 사용자가 옵트인한 경우에만, 거래처 문자의 약속·기록 자동 수집 (필수 아님, 기본 꺼짐) |
| READ_PHONE_STATE | 통화 종료 감지 → 방문 기록 생성 유도 (번호 저장 없이 이벤트 트리거 용도) |
| SYSTEM_ALERT_WINDOW | 감지 기록을 다른 앱 위 플로팅으로 즉시 확인 (옵트인) |
| BIND_NOTIFICATION_LISTENER_SERVICE | 카톡 알림 중 거래처 관련 메시지 감지 (옵트인) |
| RECORD_AUDIO | 음성 기록 입력 |
| READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE | 스크린샷 감지 (옵트인) |
| READ_CONTACTS [TODO: 실제 사용 여부 확인 — 미사용이면 매니페스트에서 제거 권장] |

> 주의: SMS/통화 기록 권한은 Play 정책상 제한적 — 앱의 핵심 기능이 아니므로
> 심사 리스크가 크다. 1차 출시에서는 감지 채널을 기본 OFF로 두고, 권한 선언 근거 문서를
> 반드시 준비할 것. 리스크가 크면 1차 빌드에서 SMS/통화 권한 제거를 검토.
