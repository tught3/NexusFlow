NexusFlow(이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 관련 법령(개인정보보호법 등)을 준수합니다.

## 1. 수집하는 개인정보
| 항목 | 수집 시점 | 이용 목적 |
|---|---|---|
| 이메일 주소, 이름(선택) | 회원가입/로그인 | 서비스 계정 식별·인증 |
| 영업 기록(텍스트·음성 전사), 거래처명·담당자명·연락처·일정 등 사용자가 입력하거나 옵트인한 감지 채널에서 수집한 정보 | 서비스 이용 중 | AI 구조화·기록 저장·인사이트 생성 등 서비스 핵심 기능 제공 |

- 음성 원본은 텍스트 변환 후 저장하지 않는 것을 기본값으로 합니다.
- 자동 감지 채널(스크린샷·SMS·카카오톡 알림·통화)은 온보딩 및 설정에서 이용자가 직접 켜고 끌 수 있으며, 기본값은 꺼짐입니다.

## 2. 개인정보의 처리 위탁
서비스 운영을 위해 아래 사업자에게 처리를 위탁합니다.
| 위탁 받는 자 | 처리하는 정보 | 위탁 업무 |
|---|---|---|
| Supabase (호스팅 인프라) | 계정 정보, 영업 기록 | 데이터 저장·인증 |
| OpenAI | 이용자가 입력한 텍스트 (AI 구조화 시) | 텍스트 구조화 처리 |

- OpenAI로 전송되는 텍스트는 서비스 기능(AI 구조화) 수행 목적으로만 사용되며, 서비스는 이를 다른 목적으로 이용하지 않도록 API 데이터 사용 설정을 적용합니다. [TODO: 옵트아웃 설정 적용 확인]

## 3. 제3자 제공
이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다.

## 4. 보유 및 파기 기간
- 계정 정보: 회원 탈퇴 시까지
- 영업 기록: 회원 탈퇴 또는 이용자가 기록을 삭제할 때까지
- 파기: 지체 없이 복구 불가능한 방법으로 전자적 파일은 삭제합니다.

- 기록 삭제: 앱 내 각 기록 삭제 기능

## 6. 안전성 확보 조치
- 전송 구간 TLS 암호화
- 데이터베이스 행 수준 보안(RLS)으로 이용자 간 데이터 격리
- 개인정보(연락처 등) 암호화 저장 기능 제공 (Secure Vault)
