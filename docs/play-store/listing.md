```
말했더니 알아서 정리됨. 음성·메시지가 거래처 기록으로, 관리할 건 AI가 알려줘요.
```

## 전체 설명 (4000자 이내)

```
영업 기록, 이제 적지 마세요. 말하세요.

NexusFlow는 영업사원을 위한 AI 관계 관리 앱입니다. 고객 방문 후 음성으로 말만 하면,
AI가 거래처·담당자·약속·할 일을 알아서 정리해 기록으로 남겨줍니다.

━━━━━━━━━━━━━━━━━━━━━━

■ 이렇게 동작해요

🎤 말로 기록 — 방문 후 스마트폰에 말만 하면 끝. 통화·메시지 내용도 자동으로 거둬요.
✨ AI 정리 — 흩어진 말에서 거래처·담당자·일정·follow-up을 추출해 구조화된 기록으로.
🔔 필요한 것만 알려줘요 — 마감 임박 follow-up, 오래 연락 안 한 거래처, 기회 신호를 AI가 찾아 알림.
📊 관계 온도계 — 접촉 빈도·반응·약속 이행으로 거래처별 관계 점수(Health Score)를 계산.
🗂 거래처·담당자 관리 — 방문 기록 타임라인, 담당자별 가용 시간대까지 한눈에.

━━━━━━━━━━━━━━━━━━━━━━

■ 이런 분께 필요해요

· 병원·약국을 돌며 기록이 쌓이는 제약영업 MR
· 고객 접점이 많은 보험 설계사
· 거래처 관리가 손글씨 메모·엑셀로 되어 있는 B2B 영업 담당자

━━━━━━━━━━━━━━━━━━━━━━

■ 안심하고 쓰세요

· 기록은 내 계정에만 저장되고 외부에 공유되지 않아요.
· AI 분석 시 텍스트만 처리되며, 음성 원본은 처리 후 삭제 기본값이에요.
· 수집 채널(음성·스크린샷·SMS 등)은 온보딩에서 직접 선택하고 언제든 끌 수 있어요.

━━━━━━━━━━━━━━━━━━━━━━

말했더니 알아서 정리됨 — NexusFlow
```
